YT Studio Uploader

Đăng video theo queue.json bằng tab YouTube Studio đang đăng nhập. AI chỉ được gọi khi một bước bị kẹt.

1. Thư mục video

Chưa chọn thư mục

Nguồn là file Excel (noi-dung-youtube.xlsx, tạo bằng tools/make_sheet.mjs) hoặc queue.json trong thư mục đã chọn. Đường dẫn video/thumbnail tính từ thư mục này. Nên đóng file trong Excel khi đang chạy để extension ghi được link YouTube vào file.

2. Hàng đợi

#Tiêu đềFileHiển thịTrạng tháiLink
Chưa có dữ liệu

3. Cài đặt

Nhà cung cấpAPI keyModelBase URL (để trống = mặc định)

Chỉ cần điền key cho AI bạn dùng. API key lưu trong chrome.storage.local của máy này, chỉ gửi tới máy chủ của chính nhà cung cấp đó. Qwen dùng tài khoản Trung Quốc đại lục thì đổi Base URL thành https://dashscope.aliyuncs.com/compatible-mode/v1. Tắt AI thì gặp lỗi tool sẽ dừng và báo bước bị kẹt.
